# GHIElectronics.Endpoint.Devices.Touch

Touchscreen support for Endpoint. The Touch class is abstract: subclass it for your panel's chip. Ships one concrete subclass, InputTouch, that wraps a kernel /dev/input/eventN (used for USB touchscreens).

Part of the [GHI Electronics Endpoint](https://github.com/ghi-electronics/Endpoint-Libraries) libraries. See the repository README for the full package list and getting-started guide.
